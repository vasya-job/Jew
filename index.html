Как это работает

  1. На Mac запущен start-efir.sh — это ваш DNS и магазин.
  2. На Hisense: Настройки → Сеть → DNS → Вручную → DNS = IP вашего Mac.
  3. Рекламные домены Hisense/VIDAA уходят в «чёрную дыру».
  4. Имя efir.home указывает на Mac — открываете магазин без длинных адресов.
  5. «Установить» сохраняет приложение на ТВ (в памяти браузера).
  6. Важно: VIDAA не Android — нельзя ставить чужие APK. Ставятся веб‑приложения и сервисы по https. Нативное приложение Apple TV на ТВ по‑прежнему лучше для 4K HDR; из Эфира удобный быстрый вход на tv.apple.com.
