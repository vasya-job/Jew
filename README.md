# Эфир

Веб-оболочка для телевизоров Hisense на VIDAA: без рекламы в интерфейсе, свои ярлыки программ, быстрый запуск Apple TV и навигация с пульта.

## Важно про VIDAA

Системный лаунчер Hisense заменить нельзя — ОС закрытая. Эфир работает как домашний экран в браузере ТВ и обходит рекламу главного экрана VIDAA, пока вы им пользуетесь.

## Как открыть на ТВ

1. Браузер на Hisense → адрес опубликованного Эфира.
2. Закладка / «на экран».
3. «Добавить» — свои https-программы.
4. В «Скорость» включите лёгкий режим на слабом SoC.

## Локально

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4173
