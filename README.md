# Эфир

Веб-оболочка для Hisense на **VIDAA**: без рекламы в интерфейсе, свои ярлыки, быстрый Apple TV, навигация с пульта.

## Открыть на телевизоре

В браузере Hisense откройте:

**https://raw.githack.com/vasya-job/Jew/main/index.html**

Добавьте в закладки. Дальше живите в Эфире вместо главного экрана VIDAA с баннерами.

Исходники: https://github.com/vasya-job/Jew

## Важно про VIDAA

Системный лаунчер Hisense заменить нельзя — ОС закрытая. Эфир работает как домашний экран в браузере и обходит рекламу главного экрана, пока вы им пользуетесь. Нативные APK «как на Android» сюда не ставятся — добавляйте https-программы через «Добавить».

## Возможности

- Сетка приложений + свои ярлыки (сохраняются на ТВ)
- Кнопка и плитка Apple TV → tv.apple.com
- Режим скорости для слабого процессора
- Стрелки пульта / OK

## Локально

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```
