# Эфир — DNS-магазин для Hisense VIDAA

Схема как у «смены DNS»: Mac становится DNS-сервером в вашей сети.

1. Рекламные домены Hisense/VIDAA блокируются.
2. Имя `efir.home` открывает магазин на Mac.
3. В магазине жмёте **Установить** — приложение появляется в «Мои приложения».

## Важно

Ваш ТВ на **VIDAA**, не Android TV. Через DNS **нельзя** ставить произвольные APK, как на приставках.  
То, что часто показывают в роликах — либо Android Hisense, либо сторонние «серые» DNS-витрины.  
Эфир делает безопасный домашний вариант: DNS-блок рекламы + установка веб-приложений/сервисов.

## Запуск на Mac (ТВ в той же сети)

```bash
cd ~/efir   # или заново: git clone https://github.com/vasya-job/Jew.git efir && cd efir
git pull
chmod +x start-efir.sh
./start-efir.sh
```

Введите пароль Mac, когда спросит (нужен для DNS на порту 53).

## Настройки на Hisense

1. **Настройки → Сеть → Сетевое подключение →** ваш Wi‑Fi/Ethernet → **DNS**
2. DNS вручную: **IP вашего Mac** (скрипт покажет его)
3. Браузер ТВ → `http://efir.home/`  
   если имя не открылось: `http://IP_МАКА/` или `http://IP_МАКА:8080/`
